Book Finder App
The Book Finder app is located inside the memory based app/book-finder.html directory and is linked directly from the main index.html hub. It uses a live Supabase PostgreSQL cloud backend configured with a project URL and public key to establish a real-time communication bridge. When opened, the app requests the book list via a public SELECT Row Level Security (RLS) policy and dynamically renders the cards on screen. When a user submits a recommendation (title, author, format, vibe, recommend_by), the JavaScript sends the entry to Supabase where an INSERT policy validates and saves it permanently to the database, instantly displaying the new book without needing a page refresh.
